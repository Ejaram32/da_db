# da_db
This web app is a simple app that allows us to analyze how the milage in a car affects its price and how is the distribution of the milage along the dataset cars.
this web app consists in two elements a check box once clicked it will provide us with a histogram of the data and a button when pressed it will show us the relationship between the odometer and the price of the car.


# Objective 

this project aims to build a simple streamlit app that uses plotly to present different graphs and explore the different tools availible on the streamlit platform for webapps, as well as practicing the use of git and github to manage our project and finally implement it and publishit on render.
 
# Data

The data used is a vehicles dataset from usa.
the variables included are:
- price
- model_year
- model
- condition
- cylinders 
- fuel 
- odometer 
- transmission 
- type  
- paint_color 
- is_4wd 
- date_posted 
- days_listed

with this variables we implemented a histogram for the dataset exploring the distribution of the milage recorded on the odometer for each car.
we also built a Scatter plot button that compares the sales price with the odometer values, this way we can analyse what is the relationship between a car price and it's milage
